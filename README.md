# MoleStudio

## 用现代的Rust+Tauri技术，为原版Mole打造一个强大的跨平台图形界面

MoleStudio 是经典系统清理工具 [tw93/Mole](https://github.com/tw93/Mole) 的现代化重构版本，采用 **Rust + Tauri** 技术栈打造，旨在以全新的 GUI 桌面体验重新定义跨平台系统维护。

## 🎯 核心能力（继承并增强自原版 Mole）

- **系统深度清理**
  一键扫描并清理 macOS / Windows / Linux 系统中的缓存、日志及临时文件。

- **应用彻底卸载**
  不仅卸载应用程序本身，还能智能识别并清除其残留的配置与缓存文件。

- **磁盘空间分析**
  可视化展示磁盘占用结构，助你快速定位“空间吞噬者”。

- **系统状态监控**
  实时监控 CPU、内存、磁盘与网络使用情况，掌握系统运行全貌。

## 🦀 技术革新亮点

- **Rust 重写核心逻辑**
  借助 Rust 的零成本抽象与内存安全保障，实现更高性能与更低资源占用。

- **Tauri 桌面框架**
  跨平台支持（macOS / Windows / Linux），应用体积小巧，安全性卓越。

- **现代化 GUI 交互**
  直观友好的图形界面，大幅降低使用门槛，提升操作效率与体验。

---

MoleStudio 致敬原作 `tw93/Mole` 的优秀设计理念，并以现代技术栈赋予其全新生命力，致力于为用户提供高效、安全、优雅的跨平台系统维护工具。
