# Mole Desktop - Tauri 架构设计文档

## 🏗️ 项目架构概述

基于 Tauri 2 + Rust 的现代化桌面应用架构，专为 macOS 系统维护工具设计。采用**单一代码库、双版本构建**策略，完美平衡 Mac App Store 合规性与功能完整性。

### 核心设计理念
- **简洁高效**: 避免过度工程化，专注于核心清理功能
- **安全优先**: 严格遵循 Apple 沙箱规范，所有操作可预览可撤销
- **性能优化**: 利用 Rust 的高性能和并发能力处理大文件扫描
- **用户体验**: 直观的 GUI 界面，保留 Mole CLI 的强大功能

## 🔧 功能模块划分

### 1. 系统监控模块 (`system`)
- **功能**: 实时 CPU、内存、磁盘、网络监控
- **技术**: `sysinfo` crate + 定时刷新
- **特点**: 轻量级，沙箱友好，无特殊权限要求

### 2. 磁盘分析模块 (`analyzer`)
- **功能**: 可视化磁盘使用情况，大文件查找
- **技术**: `jwalk` 并行扫描 + 增量缓存
- **特点**: 支持用户授权目录扫描，进度实时反馈

### 3. 文件清理模块 (`cleaner`)
- **功能**: 大文件清理、重复文件查找、安全删除
- **技术**: `trash` crate + 文件哈希比对
- **特点**: 所有删除操作移入废纸篓，支持 Dry-run 预览

### 4. 应用管理模块 (`app_manager`) - 完整版专属
- **功能**: 应用列表、残留文件查找、智能卸载
- **技术**: Bundle ID 解析 + 关联文件匹配
- **特点**: 需要 Full Disk Access 权限

### 5. 项目清理模块 (`project_cleaner`) - 完整版专属
- **功能**: 开发者项目构建产物清理
- **技术**: 模式匹配 + 智能识别
- **特点**: 自动发现 `node_modules`、[target](file:///home/a16/macos/mole-desktop/node_modules/.pnpm/@types+react@19.2.14/node_modules/@types/react/index.d.ts#L4105-L4105) 等目录

### 6. 设置和权限模块 (`settings/permissions`)
- **功能**: 应用设置管理、权限检查和请求
- **技术**: Tauri 插件 + macOS 系统 API
- **特点**: 引导用户正确授权，提升用户体验

## ⚡ 架构优势

### 1. 无插件设计（正确决策）
**清理软件不需要插件系统**，原因如下：
- **功能固定**: 系统清理的核心功能相对稳定，不需要动态扩展
- **安全考虑**: 插件系统增加安全风险，不符合 MAS 审核要求
- **维护简单**: 单一代码库更容易测试和维护
- **性能优化**: 避免插件加载开销，启动更快

### 2. 特性门控（Feature Gating）
通过 Rust 的特性系统实现双版本构建：
- **`mas` 特性**: Mac App Store 版本（精简安全）
- **`full` 特性**: 官网完整版本（功能完整）

```toml
# 构建 MAS 版本
cargo build --features mas

# 构建完整版本
cargo build --features full
```

### 3. 清晰的职责分离
- **Commands**: 仅处理前端调用，参数验证
- **Core**: 纯业务逻辑，无 Tauri 依赖
- **Models**: 数据结构定义，可序列化
- **State**: 应用全局状态管理

### 4. 易于测试
- Core 模块完全独立，可进行单元测试
- Commands 模块可通过模拟 AppHandle 进行集成测试
- 业务逻辑与 UI 逻辑完全分离

## 🔒 安全与合规

### Mac App Store 合规保证
- **无外部依赖**: 不调用任何外部二进制或脚本
- **沙箱友好**: 严格限制在用户授权目录内操作
- **透明操作**: 所有文件操作均有预览和确认
- **隐私保护**: 本地数据处理，不上传任何信息

### 官网版本安全机制
- **权限最小化**: 仅在必要时请求高级权限
- **操作审计**: 详细记录所有文件操作
- **白名单保护**: 防止误删重要系统文件
- **撤销支持**: 废纸篓操作可轻松恢复
