## 分析

### 当前实现的差距

| 维度     | 我们                                 | macOS                                          |
| -------- | ------------------------------------ | ---------------------------------------------- |
| 放大对象 | **仅**光标下的 item                  | 光标下 item **+ 相邻 item 也微量放大**         |
| 放大曲线 | 线性 `[-150, 0, 150] → [44, 52, 44]` | 非对称钟形曲线，靠近时急速放大，远离时快速衰减 |
| 弹簧感   | `damping: 12` 偏松，有点"飘"         | 紧致、有磁性吸力感，无反弹                     |
| 视觉印象 | item 自己在缩放                      | item 在"被吸/被拉近"到光标                     |

### macOS Dock 的"拉近感"

macOS 实现的核心是一个**高斯/钟形放大曲线**，不是简单的三点线性映射：

1. **非线性衰减曲线**：离鼠标越近的 item 放大越剧烈，离得越远几乎不动。我们的线性 `useTransform` 给的是均匀过渡——距离 75px 恰好放大一半，但 macOS 在距离 75px 时几乎不会放大，只对"真正接触到附近"的 item 有明显效果。

2. **相邻 item 连锁放大**：macOS 的光标附近 2-3 个 item 都参与放大，形成一条平滑的"膨胀曲线"，视觉上像整个 Dock 被手指按进去，而不是单个 item 在缩放。

3. **弹簧 "tight" 模式**：macOS 的 `damping` 接近临界阻尼（临界阻尼值 ≈ `2 * sqrt(mass * stiffness)`），没有反弹。我们现在 `damping: 12`、`stiffness: 150`、`mass: 0.1`，临界阻尼约 `7.7`，12 是过阻尼但偏松散。

### 怎么改才能靠近

1. **换放大曲线**：不用 `useTransform` 三段线性，改用自定义 `useTransform` 回调实现指数衰减放大
2. **加入相邻 item 放大**：`mouseDistance` 的映射范围让相邻 item 也有微量放大（把有效距离拉到涵盖上下紧邻 item 的范围）
3. **调弹簧参数**：提高 `stiffness` 到 250-300，`damping` 调高到接近临界值，去掉弹性感
4. **放大曲线公式思路**：`scale(baseSize, mag, baseSize + (mag - baseSize) * exp(-(dist^2) / (sigma^2)))`，sigma 控制在 80-100 之间，让放大只在靠近时有
