- mole_clean 是阻塞式命令 ：当前 mole_clean 是 pub async fn 但内部用 spawn_blocking ，它返回 Result<Value> 即全部结果。在 useTauri 中 invoke 是 promise 形式的，这意味着 前端 await tauri.mole_clean() 会等整个扫描完成才 resolve ，与此同时 IPC 事件在中间推送。页面需要把 invoke 放进 Promise 但不阻塞 UI，同时通过事件监听获取中间进度。
- useScannerProgress 的 totalKb 累计逻辑 ：在 Clean.tsx 里 phase-result 会累加 sizeKb ，但这是 React state。如果组件重 mount， totalKb 从 0 开始累加，但后续事件的数值是累加的（Rust 每次给当次模块的增量），不影响最终展示。
- 多页面同时扫描 ：后端 mole_clean 大概率不支持并发（有全局锁），但前端不应允许两个页面同时开扫。 ScanSessionsContext 可以在 registerSession 时检查。

### 后续其他页面接入示例

```tsx
// pages/ShellClean 等
import { useScanSessions } from '@/layout/ScanSessionsContext'
import { useScanButton } from '@/layout/ScanButtonContext'

function ShellClean() {
  const { setState } = useScanButton()
  const { registerSession, updateSession, getSession } = useScanSessions()

  useEffect(() => {
    const existing = getSession('clean')
    if (existing) {
      // 恢复会话（切回来）
      setState({ visible: true, percent: existing.progress, label: '扫描中', ... })
    } else {
      registerSession({ id: 'clean', status: 'idle', progress: 0 })
      setState({ visible: true, percent: 0, label: '扫描', onClick: startScan })
    }
    return () => setState({ visible: false })
  }, [])

  // 监听 IPC 事件，实时更新 session + button
  useEffect(() => {
    const ac = new AbortController()
    tauri.onIpcEvent(EVT_CLEANUP_PHASE_RESULT, (payload) => {
      const progress = calcProgress(payload)
      updateSession('clean', { progress })
      setState({ percent: progress, label: '扫描中' })
    }, ac.signal)
    return () => ac.abort()
  }, [])
}
```
